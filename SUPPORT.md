# Support

## Getting Help

If you have questions about using `sweepr`, running file sweeps, or configuring custom workflows:

1. **Documentation**: Review the [README](README.md) and [CONTRIBUTING.md](CONTRIBUTING.md).
2. **Supported Categories**: Run `sweepr types` in your terminal to see all recognized file categories and extensions.
3. **Issue Search**: Check existing [closed and open issues](https://github.com/amandeavor/sweepr/issues) to see if your question or issue has already been discussed.
4. **New Issues**: If you suspect a bug or need a feature, open an issue using the appropriate template.
